# 个人信息库使用说明

## 概述

`personalInfo.ts` 文件用于将你的个人信息格式化为 AI 友好的格式，以便 AI 助手能够准确回答关于你的问题。

**所有个人信息都直接硬编码在 `formatPersonalInfoForAI` 方法中，便于集中修改。**

## 数据结构

个人信息库包含以下主要部分：

### 1. 基本信息 (basicInfo)
- 姓名（中英文）
- 个人简介（中英文）

### 2. 教育背景 (education)
- 学校名称
- 学位
- 时间范围
- GPA
- 导师信息
- 核心课程列表

### 3. 工作经历 (internship)
- 实习/工作公司
- 职位
- 时间范围
- 主要职责列表

### 4. 项目经历 (projects)
- 项目名称
- 时间范围
- 项目描述列表

### 5. 获奖经历 (awards)
- 奖项名称
- 获奖情况
- 相关项目
- 个人贡献

### 6. 技能 (skills)
- 编程语言
- 框架/库
- 工具
- 平台

## 如何更新个人信息

### 直接修改 formatPersonalInfoForAI 方法

所有个人信息都硬编码在 `formatPersonalInfoForAI` 方法中，位于 `src/data/personalInfo.ts` 文件。

**修改步骤：**

1. 打开 `src/data/personalInfo.ts` 文件
2. 找到 `formatPersonalInfoForAI` 方法
3. 在方法开头的 `========== 个人信息配置区域 ==========` 标记处修改个人信息
4. 所有信息都分为中英文两部分，分别修改即可

**示例：修改基本信息：**

```typescript
// 基本信息
const basicInfo = {
  zh: {
    name: '你的中文名',
    description: '你的中文简介'
  },
  en: {
    name: 'Your English Name',
    description: 'Your English Description'
  }
};
```

**示例：添加新项目：**

```typescript
// 项目经历
const projects = {
  zh: [
    {
      name: '项目名称',
      date: '2024年1月 - 2024年3月',
      description: [
        '项目描述1',
        '项目描述2'
      ]
    },
    // ... 添加更多项目
  ],
  en: [
    // 对应的英文版本
  ]
};
```

## 系统提示词格式

`formatPersonalInfoForAI` 函数会将个人信息格式化为结构化的系统提示词，包含：

1. **清晰的章节划分**：使用 Markdown 格式，便于 AI 理解
2. **结构化信息**：每个部分都有明确的字段和格式
3. **回答要求**：指导 AI 如何基于这些信息回答问题

### 提示词特点

- **准确性**：只基于提供的信息回答，不编造
- **专业性**：回答要专业、友好
- **语言支持**：支持中英文两种语言
- **简洁性**：回答要简洁明了，重点突出

## 最佳实践

1. **保持信息更新**：定期更新个人信息，确保 AI 回答的准确性
2. **结构化数据**：使用列表和清晰的格式，便于 AI 解析
3. **完整性**：尽量包含所有相关信息，但避免冗余
4. **语言一致性**：确保中英文信息对应一致
